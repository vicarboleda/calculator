# Calculadora

Calculadora hecha con HTML, CSS y JavaScript puro (módulos ES), como práctica
de maquetación, manejo del DOM y organización de código.

## Cómo correrla

Abrir `index.html` con la extensión Live Server de VSCode
(los módulos ES no funcionan abriendo el archivo con doble clic).

## Estructura

- `js/operations.js`: operaciones matemáticas (add, subtract, multiply, divide).
- `js/display.js`: formato del resultado y actualización de la pantalla.
- `js/main.js`: punto de entrada.
